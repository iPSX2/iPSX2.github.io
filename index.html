PlayStation 2 games on iPhone and iPad

iPSX2 is a free, open-source PS2 emulator for iOS. It runs games with a JIT recompiler for arm64 and renders with Metal. It is built on PCSX2 and ARMSX2.

Download Source code

iPSX2 does not include a PS2 BIOS or any games. Dump them from hardware you own.

What it does

A full PS2 core with a touch-first frontend built for iPhone and iPad.

JIT recompiler

The EE, IOP and VU recompilers generate arm64 code at runtime. JIT is enabled through StikDebug.

Metal renderer

Hardware rendering with upscaling up to 8×, texture filtering, FXAA and CAS sharpening.

Per-game tweaks

Override settings for a single game, and turn built-in patches and cheat codes on or off per game.

Game library

Folders, cover art, custom titles and play time for your collection.

Touch and controllers

A virtual pad with a drag-to-edit layout, plus MFi and other Bluetooth controllers.

Speed control

Fast-forward, slow motion, frame advance, and performance options such as MTVU and EE cycle skip.

Requirements

  • An iPhone or iPad with an arm64 chip, running iOS 18 or newer (tested on iOS 18 and iOS 26).
  • A way to sideload apps. A free Apple developer account works.
  • StikDebug to enable JIT. Without JIT, iPSX2 falls back to the interpreter, which is too slow for most games.
  • A PS2 BIOS dump.

Install

Releases are unsigned .ipa files that you sign when you install them.

  1. Download the latest releaseGet the .ipa from the Releases page.
  2. Sign and install itUse Sideloadly, AltStore, SideStore, plumesign or a similar tool.
  3. Add your BIOS and gamesOpen iPSX2 once so its folder is created, then copy files in with the Files app or the in-app importer.
  4. Enable JIT and playLaunch iPSX2 from StikDebug with the legacy script, then start a game.

Build it yourself

The simplest route is GitHub Actions: fork the repository, run Build Unsigned IPA from the Actions tab, and download the artifact. On a Mac:

cmake -S cpp -B build-device -G Xcode \
  -DCMAKE_SYSTEM_NAME=iOS -DiPSX2_REAL_DEVICE=ON
xcodebuild -project build-device/iPSX2.xcodeproj \
  -scheme iPSX2 -sdk iphoneos -configuration Release \
  CODE_SIGNING_ALLOWED=NO archive
